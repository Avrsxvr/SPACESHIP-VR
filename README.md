Overview: 

SpaceShip-VR is an immersive virtual reality spaceship simulation built using Unity and the XR Interaction Toolkit. The project focuses on realistic interaction systems, multiple locomotion methods, and comfort-aware VR design.

Features
 1. Physics-based grabbing, weapon handling, and socket interactions
 2. Multiple locomotion systems including smooth movement, turning, ladder climbing, and seated navigation
 3. Interactive controls using levers and buttons
 4. Emphasis on interaction stability and VR user comfort

Tech Stack
 1. Unity
 2. XR Interaction Toolkit

Setup:
1. Open the project in Unity (XR-supported version)
2. Ensure XR Interaction Toolkit is installed via Package Manager
3. Set up a compatible VR headset
4. Press Play to run the scene
